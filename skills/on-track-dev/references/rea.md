# REA 的可选职责

官方：https://github.com/morluto/rea
Skill：https://github.com/morluto/rea/blob/main/.agents/skills/reverse-engineer-anything/SKILL.md
核对日期：2026-11-13。版本变化时重新核对真实能力；不把 main 中的指令当成已安装服务的功能清单。

仅在目标依赖发布产物、反编译或运行观察时使用。完整源码架构分析直接读代码；解释当前项目不要求安装 REA。

先明确调查问题、目标路径及所需证据。检查当前可用工具；缺少 MCP/引擎时说明缺口，继续源码等独立工作，不自动安装整套引擎。Skill 文件本身不赋予工具能力。安装/配置须在授权范围，优先固定已核对版本。

调查报告分观察、推断、未知，保留证据身份、覆盖范围与限制。静态关系不能证明运行行为，反编译结果不能称为原始源码。调查所得不能自动修改项目需求。

结束时按实际 REA 文档关闭自建会话，必要时显式保存一份可恢复证据；不假定内存记录会跨进程持久化。大型缓存只登记位置与用途，不在每轮复制。证据可能含目标数据，不将其无条件提交 Git。

本套件未复制上游 Skill，也不安装 REA。方法参考：obra/superpowers 的完成前验证与根因调查、mattpocock/skills 的设计质询及决策记录、GitHub spec-kit 的规格驱动；只借鉴必要机制，不继承整个工作流或权限。
